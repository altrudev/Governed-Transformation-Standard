# GTS publication and commercial-rights boundary

| Asset | Currently operative rights | Intended future decision |
|---|---|---|
| Specification, narrative documents and examples | Repository LICENSE: CC BY-NC 4.0 unless a file-specific license applies | Clarify testing by commercial organizations in a separate amendment |
| Public schemas and test vectors | Repository LICENSE, subject to applicable copyright law | Confirm whether public implementation needs additional permission |
| Reference adapter source code | No explicit software license currently granted | Select a file-specific software license or narrow evaluation license after review |
| Independent evaluation reports | Copyright and license of the submitting author | Require contributors to disclose licenses and independent reuse permissions |
| Frequency/DDC private implementations | No public license granted here | Commercial agreements negotiated separately |
| GTS name, logos, certification claims | No trademark/certification grant in LICENSE | Publish mark-use and assessor designation policy after legal review |

These are publication rights and licensing boundaries, not technical proofs of implementation, trade secret status or enforceability. A copyright license cannot by itself reserve exclusive rights to functionality independently implemented without copying.
